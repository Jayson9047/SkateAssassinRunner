# Cash dash collision fix

Scenario1 and Scenario2 both reference `Assets/Prefabs/Props/Obstacles/GameObject.prefab` (GUID bab5c63c74859c8439f092f487045734). It uses KillsPlayerOnTouch_SlideAware and therefore inherits the earlier shared hazard sweep. No additional obstacle edits were necessary.

Updated `Assets/ThirdParty/InGame/InfiniteRunnerEngine/Common/Scripts/PickableObjects/Coin.cs` to use the existing SweptBoxIntersection geometry check in LateUpdate. Cash now checks the player's relative movement across each pickup between frames, including moving pickups and airborne movement. Native triggers still work. Both paths use a once-per-activation claim, so returning through a collected stack or receiving duplicate callbacks cannot award cash twice. Re-enabling pooled cash resets both the claim and movement history. Existing amount, effects, sound and AddCash behavior are retained.

Unity 6000.0.67f1, Infinite Runner Engine 2.1. Compilation succeeded. A focused paused Play Mode regression used the actual player, six actual Cash prefab instances and the real cash counter. A single 16-unit horizontal displacement at airborne height collected all six and added 60 cash. Returning through them and explicitly delivering duplicate native callbacks left the total at 60. An off-path elevated control remained uncollected. Reactivating a collected pickup did not create a stale-path hit and awarded exactly 10 on the next crossing. Test objects were destroyed, player position and cash restored, and Play Mode stopped. No scene, pool or prefab configuration was saved.

This is a deterministic fast-movement integration check, not a full double-jump/dash input playthrough. The checked Scenario4 prefab currently contains no Coin components; verification therefore used the actual shared Cash prefab instead of claiming a Scenario4 encounter test. Detection covers the existing 3D box pickup/player colliders and translational movement; it is not general continuous angular collision. Preserve the project Coin patch when upgrading the vendor package.
